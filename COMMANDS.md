# Commands

## Setup
- `npm install` — install dependencies.

## Development
- `npm run dev` — start Vite dev server (fixed port 5173).
- `npm run electron:dev` — run Electron with the Vite dev server.
- `npm run preview` — preview the built renderer bundle.

## Build
- `npm run build` — compile main process and build renderer.
- `npm run electron:build` — build/package the Electron app.

## Notes
- Port 5173 must be free for `npm run dev` and `npm run electron:dev`.
